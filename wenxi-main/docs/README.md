# 文析助手文档

文析助手支持 Android 和 Windows，接入 17 个网盘与 GitHub 文件源，提供链接与口令解析、多账号文件管理、搜索、上传下载、在线播放和设备互联，也支持自定义主题与背景。

功能介绍见 [项目 README](../README.md)，高清宣传图与单页原图见 [安卓界面](../README.md#安卓界面) 和 [Windows 界面](../README.md#windows-界面)。以下为编译、发布及其他说明。
