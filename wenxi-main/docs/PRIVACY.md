# 隐私与网络访问

文析助手直接与用户选择的网盘服务通信。网盘登录、文件列表、上传、下载和播放会向对应服务发送操作必需的凭据和参数；这些服务的隐私政策与账号限制也适用。

百度个人网盘，以及分享页选择“账号下载”后的下载与播放取链请求，会将当前用户的必要登录凭据、文件标识和客户端参数加密发送到构建者配置的取链服务，由该服务使用该用户自己的账号向百度请求下载地址。配套服务不保存账号凭据或文件内容，不记录 Cookie、文件路径和完整下载链接；返回的临时链接仍由客户端直接连接百度读取文件。服务不可用时会显示取链失败。

百度分享链接默认使用“公益解析”，会向 [mf.dg22.top](https://mf.dg22.top) 发送所选分享链接、提取码、分享文件标识和解析密码，用于列出文件并获取下载地址；不会向该站发送用户的百度账号 Cookie、Token 或账号密码。每天首次打开或跨天返回应用时，会在后台读取配置的语雀公开文档，提取最新 UC 口令，以游客身份获取对应文本，只读取文件开头并提取第一行的中文作为解析密码。密码按北京时间每日更新，在本地加密缓存；当天成功更新后复用缓存，密码被拒绝时会重新拉取。主来源不可用或密码被拒绝时，尝试从构建者配置的 Gitee 文本地址获取备用密码；重试次数有上限，后台更新失败不阻止应用启动。密码更新不使用用户的 UC 账号，不向语雀、Gitee 发送网盘凭据，也不会生成下载任务。文件由客户端使用站点返回的下载参数直连百度读取。解析页与分享页均可切换为“账号下载”；公益站有独立的服务限制和隐私政策。


账号凭据、保存的密码和应用状态使用项目已有的本地加密存储。加密备份由用户主动导出，需要自行保管备份文件与密码。备份即使加密也不应放入 GitHub、公开 Issue 或 PR。

设备互联在手机端由用户手动开启，在电脑端进入页面时开启，通过局域网发现设备并直接传输所选文件、文件名和主动发送的文字、链接，不经过中转服务器。设备连接使用临时连接码，文件分享链接带随机凭据；持有链接且位于同一局域网的设备可下载对应文件。连接使用局域网 HTTP，请在可信网络内使用，分享结束后可主动关闭；收件箱保存在本地加密状态中。

手机点击“扫码连接”时才请求相机权限，二维码在本机识别，不保存或上传相机画面。连接二维码包含局域网地址、设备标识和本次临时连接码，关闭互联后失效；扫码配对复用现有设备连接流程，文件分享二维码先显示待接收文件，由用户选择下载。

故障日志在本机记录和轮换，由用户主动导出；应用不会自动把诊断 ZIP 上传至项目仓库。日志脱敏不能代替人工检查，反馈时应清理 Cookie、Token、账号、真实文件名、分享链接和本机路径。


启用远程配置的构建会访问构建者设置的 HTTPS 地址，用于公告、平台可用性、帮助说明和更新信息。配置取得后按内容处理，revision 和 ID 不作为必须递增的采用条件。

只有主地址访问失败时，才查询配置的 GitHub 仓库正式 Releases；预发布版和草稿不会提示为正式更新。社区构建默认不配置这些地址。配置服务、GitHub、下载镜像或 CDN 可以获知正常 HTTP 请求包含的网络信息，例如 IP 地址与 User-Agent；应用不会将网盘登录凭据附加到这些配置请求。

BT 功能会连接 tracker 和对等节点，参与的节点可能看到本机的网络地址。媒体原生依赖在构建时下载；系统没有可用字幕字体时，应用可能按需下载已固定散列的 Noto Sans SC 字体。


Android 版本内置友盟+移动统计 SDK，保留当前默认启用及既有授权状态的处理方式，统计应用启动、活跃设备和前台使用时长。当前依赖版本见 `android/gradle/libs.versions.toml`；公开构建也保留 SDK。

统计服务可能处理设备标识符（如 Android ID、OAID、广告标识符）、设备型号、系统和应用版本、网络类型、IP 地址及应用使用统计。应用关闭了 SDK 的 IMEI、IMSI、ICCID、Wi-Fi MAC 和应用列表采集，以及 SDK 的自动崩溃捕获。

应用没有向统计接口提交网盘账号、密码、Cookie、分享链接、文件名或播放内容。统计 SDK 自身的数据处理规则见 [友盟隐私政策](https://www.umeng.com/page/policy)。服务提供方为友盟同欣（北京）科技有限公司、北京锐讯灵通科技有限公司。Windows 未接入该 Android SDK。
